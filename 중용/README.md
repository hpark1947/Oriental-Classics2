# 중용(中庸)

## 개요

| 항목 | 내용 |
|------|------|
| 원전 | 예기(禮記) 제31편 |
| 저자 | 자사(子思, 공자의 손자) |
| 독립 편찬 | 주희(朱熹)가 사서(四書)의 하나로 독립시킴 |
| 구성 | 33장 |
| 핵심 사상 | 중(中), 용(庸), 성(誠), 천인합일(天人合一) |
| 성격 | 유학의 형이상학적 철학서, 성리학의 이론적 기초 |

## 중용이란?

중용(中庸)은 '치우치지 않는 떳떳한 도리'를 뜻합니다. **중(中)**은 어느 한쪽에 치우치지 않는 것이고, **용(庸)**은 평상(平常), 즉 일상에서 변하지 않는 떳떳한 도리입니다.

공자의 손자 **자사(子思)**가 지었다고 전해지며, 원래 예기의 한 편이었으나 주희가 독립시켜 사서의 하나로 삼았습니다. 주희는 사서의 학습 순서를 대학 → 논어 → 맹자 → 중용으로 정했는데, 중용을 **가장 나중에 읽도록** 한 것은 그만큼 심오하고 깊은 내용이기 때문입니다.

중용은 단순한 도덕론이 아니라, **천(天)과 인(人)의 관계**, **성(性)과 도(道)의 본질**, **성(誠)의 형이상학**을 다루는 유학의 가장 깊은 철학서입니다.

## 핵심 사상

### 1. 천명지위성(天命之謂性)
하늘이 명한 것을 본성(性)이라 하고, 본성을 따르는 것을 도(道)라 하고, 도를 닦는 것을 교(敎)라 한다. 중용의 첫 문장이자 유학 형이상학의 출발점.

### 2. 중화(中和)
희노애락이 아직 발하지 않은 상태를 중(中)이라 하고, 발하여 절도에 맞는 것을 화(和)라 한다. 중과 화를 이루면 천지가 제자리를 잡고 만물이 자라난다.

### 3. 성(誠)
성(誠, 참됨)은 하늘의 도이고, 성실하고자 하는 것(誠之)은 사람의 도이다. 성은 중용 후반부의 핵심 개념으로, 천도와 인도를 잇는 다리.

### 4. 중용지도(中庸之道)
극단으로 치우치지 않고 일상에서 변함없이 도를 실천하는 것. 쉬워 보이지만 가장 실천하기 어려운 최고의 덕.
