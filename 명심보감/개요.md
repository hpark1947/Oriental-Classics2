# 명심보감 개요

---

## 1. 정의

명심보감(明心寶鑑, Myeongshimbogam)은 중국과 한국의 여러 고전에서 선현들의 금언(金言)·격언(格言)을 모아 엮은 **처세·수양 격언집**이다. '명심(明心)'은 '마음을 밝게 한다', '보감(寶鑑)'은 '보배로운 거울'이라는 뜻으로, 전체 서명은 **"마음을 밝혀 주는 보배로운 거울"**이라는 의미를 지닌다.

유교·도교·불교의 가르침을 종합적으로 수록하여, 특정 학파에 치우치지 않고 보편적 윤리와 도덕을 추구한 것이 특징이다.

---

## 2. 편찬 과정

명심보감의 저자에 관해서는 두 가지 학설이 존재한다.

### 고려 저자설 — 추적(秋適)

| 항목 | 내용 |
|------|------|
| 이름 | 추적(秋適) |
| 생몰년 | 1246~1317년 |
| 시대 | 고려 충렬왕 때 |
| 관직 | 예문관제학(藝文館提學) |
| 편찬 목적 | 왕자들과 학생들을 가르칠 목적 |

추적은 "후학들이 이익을 따르고 의로움을 잊을 것을 근심하여" 여러 고전에서 금언을 추려 명심보감을 편찬하였다.

### 명나라 증보설 — 범립본(范立本)

| 항목 | 내용 |
|------|------|
| 이름 | 범립본(范立本) |
| 시기 | 명나라 홍무 26년(1393년) |
| 역할 | 추적의 원본에 추가 고전 문구를 보강하여 증편본 편찬 |

현재 학계에서는 **추적이 원편집자이고, 범립본이 증보편집자**로 보는 견해가 유력하다.

---

## 3. 편찬 목적

- 착하고 바르고 지혜로운 마음을 심어주는 것이 목표
- 비도덕적 행위를 금하고 양심과 도리에 맞는 생활을 권장
- 어린 학생부터 어른까지 쉽게 이해할 수 있는 교훈을 제공

---

## 4. 사상적 토대

명심보감에 인용된 출전은 매우 다양하다.

### 유교 경전
- 사서(四書): 논어, 맹자, 대학, 중용
- 공자가어(孔子家語)
- 소학(小學), 근사록(近思錄)
- 경행록(景行錄), 성심잡언(省心雜言)

### 도교 경전
- 노자(老子), 장자(莊子)
- 태공가교(太公家敎)

### 불교 경전
- 각종 불교 경전의 인과응보 관련 교훈

### 기타
- 한서(漢書), 사기(史記) 등 역사서
- 순자(荀子), 한비자(韓非子) 등 제자백가
- 안씨가훈(顔氏家訓), 소학(小學) 등 교훈서

## 5. 구성

### 전체 구성
- **상하 2권 1책**
- **원본 20편** (증보판은 최대 24~25편)
- 성심편(省心篇)이 상·하로 나뉘어 전체 분량의 약 1/3을 차지

## 7. 역사적 영향

### 한국에서의 역할
- **서당 교육의 핵심 교재**: 천자문 → **명심보감** → 소학 → 사서삼경 순으로 학습
- 고려 말 이후 가정과 서당에서 아동의 기초 교재로 널리 사용
- 수백 년간 우리 민족의 정신적 가치관 형성에 기여
- 권력자와 민중 구별 없이 각 계층에 윤리적 교훈을 전달

### 국제적 영향
- **일본**: 무로마치 시대(14~16세기)부터 수용, 에도 시대까지 광범위한 영향
- **필리핀**: 스페인 선교사들이 마닐라 화교를 통해 접하여 스페인어로 번역
- 동아시아 한문 문화권 전반에 걸쳐 영향
