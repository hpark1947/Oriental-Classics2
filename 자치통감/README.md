## 자치통감이란?

자치통감(資治通鑑)은 **북송의 명재상·사학자 사마광이 19년에 걸쳐 편찬한, 1,362년의 중국사를 시간 순으로 정리한 294권의 거대한 편년체 통사**입니다.

서명 「**자치통감(資治通鑑)**」은 신종이 직접 지은 것으로, **"통치(治)에 도움이 되도록(資) 옛일을 통합적으로(通) 거울 삼는(鑑) 책"**이라는 뜻입니다.

사기(史記)가 「인간의 역사」라면, 자치통감은 「통치의 역사」입니다. 사마광은 명확한 목적의식으로 — **"옛 잘못이 오늘 반복되지 않도록 하겠다"** — 1,362년의 사례를 시간 순으로 꿰뚫어, 218회의 「신광왈(臣光曰)」 사평으로 직접 정치 원리를 가르칩니다.

## 핵심 사상 — 「자치(資治)」 — 통치의 거울

### 1. 정명(正名) — 이름이 곧 질서
권1 첫 「臣光曰」 — **"天子之職莫大於禮, 禮莫大於分, 分莫大於名"**.
신하가 군주의 자리를 빼앗는 것을 천자가 인정해주면 모든 혼란이 시작된다.

### 2. 민본(民本) — 백성이 근본
**"民惟邦本, 本固邦寧"**을 통감 곳곳에서 환기. 민이 흩어지면 왕조가 망한다.

### 3. 인재(人材) — 사람이 곧 정치
**"夫蓄人才者, 國家之大本也"**. 누구를 등용하는가가 시대의 운명을 결정.

### 4. 간언(諫言) — 두루 들음
**"兼聽則明, 偏信則暗"**. 위징과 당 태종의 관계가 모범.

### 5. 수성(守成) — 창업보다 어려운 지킴
**"創業之難已往, 守成之難方來"**. 왕조의 진짜 시험은 2~3대.

## 16개 왕조 시대 구분

```
주(5권) → 진(3권) → 한(60권) → 위(10권) → 진晉(40권)
→ 송·제·양·진陳(남조 58권) → 수(8권)
→ 당(81권) → 오대 5왕조(29권)
```

- **당 81권** — 자치통감의 무게 중심. 안사의 난·환관 정치·번진 할거.
- **한 60권** — 통일 제국의 모범과 한계.
- **진(晉) 40권** — 사대부의 시대.

## 편찬 과정 — 19년의 침잠

사마광은 왕안석의 신법에 반대해 정치적으로 패배한 후, **1071년부터 1086년까지 15년간 변경(汴京)을 떠나 낙양(洛陽)에 칩거하며 통감 편찬에만 몰두**했습니다. 자호 「**우수(迂叟)**」 — 우원한 노인.

**3단계 작업법**: 총목(叢目, 자료 카드) → 장편(長編, 풍성한 초고) → 정본(定本, 사마광 최종 정리). 현대 역사학의 「실증 → 종합 → 해석」을 11세기에 체계화.

## 한 문장 요약

> **『자치통감』은 송의 사마광이 19년에 걸쳐 1,362년의 중국사를 294권 약 300만 자로 정리한, 「통치에 도움이 되도록 옛일을 거울 삼는다」는 명확한 목적의식의 편년체 통사이며, 「신광왈」 218개의 사평으로 정치 원리를 직접 가르치는 동양 1,000년의 「제왕학 절대 교본」이자 「판단의 학교」다.**
