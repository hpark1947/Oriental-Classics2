# 주역(周易) / 역경(易經)

## 개요

| 항목 | 내용 |
|------|------|
| 명칭 | 주역(周易), 역경(易經) |
| 기원 | 복희(伏羲)의 팔괘 → 문왕(文王)의 64괘·괘사 → 주공(周公)의 효사 → 공자(孔子)의 십익 |
| 시대 | 은·주 교체기(BC 12세기경) ~ 전국시대 |
| 구성 | 상경(上經) 30괘 + 하경(下經) 34괘 + 십익(十翼) |
| 핵심 사상 | 음양(陰陽), 변역(變易), 불역(不易), 간역(簡易) |
| 성격 | 유가 오경(五經)의 으뜸, 동양 철학의 근본 경전 |

## 주역이란?

주역(周易)은 동양 사상의 가장 근본이 되는 경전으로, **우주의 변화 원리**를 음(陰)과 양(陽)의 조합으로 설명합니다. '주(周)'는 주나라를, '역(易)'은 변화(變化)를 뜻합니다.

원래 점(占)을 치기 위한 점서(占書)로 시작되었으나, 공자 이후 우주의 이치와 인간의 도리를 담은 **철학서**로 승격되어 유가 오경의 첫머리('군경지수, 群經之首')에 놓이게 되었습니다.

## 역(易)의 세 가지 의미

1. **변역(變易)**: 만물은 끊임없이 변한다. 변하지 않는 것은 없다.
2. **불역(不易)**: 변화 속에 변하지 않는 법칙(이치)이 있다.
3. **간역(簡易)**: 복잡해 보이는 변화도 그 원리는 간단하다(음과 양).

## 기본 구조

### 효(爻)와 괘(卦)
- **효(爻)**: 주역의 최소 단위. 양효(⚊, 실선)와 음효(⚋, 끊긴 선)
- **괘(卦)**: 효를 쌓아 만든 상징 기호
  - 3효 → 소성괘(小成卦) = 팔괘(八卦)
  - 6효 → 대성괘(大成卦) = 64괘

### 팔괘(八卦)

| 괘 | 이름 | 자연 | 성질 | 가족 |
|----|------|------|------|------|
| ☰ | 건(乾) | 하늘(天) | 건강, 강건 | 아버지 |
| ☷ | 곤(坤) | 땅(地) | 유순, 포용 | 어머니 |
| ☳ | 진(震) | 우레(雷) | 움직임, 진동 | 장남 |
| ☴ | 손(巽) | 바람(風) | 들어감, 순종 | 장녀 |
| ☵ | 감(坎) | 물(水) | 빠짐, 험난 | 중남 |
| ☲ | 이(離) | 불(火) | 밝음, 아름다움 | 중녀 |
| ☶ | 간(艮) | 산(山) | 그침, 멈춤 | 소남 |
| ☱ | 태(兌) | 연못(澤) | 기쁨, 소통 | 소녀 |

### 64괘의 구성
팔괘를 위아래로 두 개씩 겹쳐 64괘를 만듭니다.
- **상괘(上卦, 외괘)**: 위의 3효 → 바깥 상황, 외부 환경
- **하괘(下卦, 내괘)**: 아래의 3효 → 안의 상황, 내면 상태

### 괘사(卦辭)와 효사(爻辭)
- **괘사(卦辭)**: 각 괘 전체의 의미와 판단 (문왕 작)
- **효사(爻辭)**: 각 효(6개)의 구체적 의미와 상황 (주공 작)
- 양효의 위치: 초구(初九), 구이(九二), 구삼(九三), 구사(九四), 구오(九五), 상구(上九)
- 음효의 위치: 초육(初六), 육이(六二), 육삼(六三), 육사(六四), 육오(六五), 상육(上六)

## 십익(十翼) - 공자의 해설

| 번호 | 이름 | 내용 |
|------|------|------|
| 1-2 | 단전(彖傳) 상·하 | 괘사에 대한 해설 |
| 3-4 | 상전(象傳) 상·하 | 괘상(卦象)과 효상(爻象)에 대한 해설 |
| 5-6 | 계사전(繫辭傳) 상·하 | 주역의 원리와 철학에 대한 종합 논의 |
| 7 | 문언전(文言傳) | 건괘·곤괘에 대한 상세 해설 |
| 8 | 설괘전(說卦傳) | 팔괘의 의미와 상징 해설 |
| 9 | 서괘전(序卦傳) | 64괘의 순서와 그 이유 해설 |
| 10 | 잡괘전(雜卦傳) | 64괘를 짝지어 간략히 해설 |
