# 소학(小學)

## 개요

| 항목 | 내용 |
|------|------|
| 편찬자 | 주희(朱熹, 1130~1200)와 유청지(劉清之) |
| 시대 | 남송(南宋) |
| 학파 | 유가(儒家) - 성리학 |
| 구성 | 내편 4편 + 외편 2편, 총 6편 |
| 핵심 주제 | 어린이와 청소년의 기본 교육, 일상의 예절과 도리 |
| 성격 | 유학 입문서, 초등 교육 교재 |

## 소학이란?

소학은 남송의 대학자 **주희(朱子)**가 제자 유청지와 함께 편찬한 유학 입문 교육서입니다. '소학(小學)'이란 '작은 배움', 즉 **대학(大學)에 들어가기 전에 먼저 배워야 할 기초 교육**을 뜻합니다.

주희는 사람이 대학의 심오한 학문(격물치지, 수신제가치국평천하)을 배우기 전에, 먼저 일상생활에서의 기본적인 예절, 부모에 대한 효도, 어른에 대한 공경, 몸가짐과 마음가짐을 익혀야 한다고 보았습니다. 소학은 바로 이 **기본 교육의 교과서**입니다.

조선시대에는 서당에서 천자문, 동몽선습 다음으로 배우는 필수 교재였으며, 조선 사대부의 인격 형성에 지대한 영향을 미쳤습니다.

## 구성

소학은 **내편(內篇)**과 **외편(外篇)**으로 나뉩니다.

### 내편(內篇) - 원리와 규범

| 편 | 편명 | 핵심 내용 |
|----|------|-----------|
| 1 | 입교(立敎) | 교육의 확립. 태교부터 성인 교육까지의 단계별 교육 원리 |
| 2 | 명륜(明倫) | 인륜을 밝힘. 부자, 군신, 부부, 장유, 붕우의 오륜 |
| 3 | 경신(敬身) | 몸을 공경함. 마음가짐, 옷차림, 음식, 언행의 예절 |
| 4 | 계고(稽古) | 옛것을 상고함. 입교·명륜·경신을 실천한 역사적 인물 사례 |

### 외편(外篇) - 보충과 확장

| 편 | 편명 | 핵심 내용 |
|----|------|-----------|
| 5 | 가언(嘉言) | 아름다운 말씀. 선현들의 명언과 교훈적 말씀 모음 |
| 6 | 선행(善行) | 선한 행실. 선현들의 모범적 행실 사례 모음 |

## 소학의 교육 철학

### 1. 쇄소응대진퇴(灑掃應對進退)
물 뿌리고 쓸기(청소), 응답하고 대답하기(언어), 나아가고 물러남(행동) - 일상의 작은 실천이 교육의 출발점

### 2. 선소학 후대학(先小學 後大學)
작은 배움을 먼저 하고 큰 배움을 나중에 한다. 기본을 갖추지 않으면 높은 학문도 의미가 없다.

### 3. 습여성성(習與性成)
습관이 본성을 이룬다. 어릴 때 몸에 밴 예절과 도리가 평생의 인격이 된다.
