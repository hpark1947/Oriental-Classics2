## 한비자란?

한비자는 전국시대 말기 한(韓)나라 공자(公子) 출신의 사상가 **한비**가 저술한 법가 사상의 집대성서입니다. 한비는 순자(荀子)에게 배웠으나, 스승의 유가적 예치(禮治) 대신 **법치(法治)**를 주장했습니다.

한비는 말을 더듬는 장애가 있었으나 글재주가 뛰어나, 자신의 사상을 문장으로 남겼습니다. 진시황이 그의 글을 읽고 감탄하여 만나기를 원했으나, 동문 이사(李斯)의 모함으로 옥중에서 독약을 마시고 생을 마감했습니다.

## 핵심 사상: 법(法) · 술(術) · 세(勢)

- **법(法)**: 성문화된 법률. 모든 사람에게 공평하게 적용되는 객관적 기준
- **술(術)**: 군주가 신하를 다루는 통치 기술. 인사 관리와 감찰의 방법
- **세(勢)**: 군주의 권위와 권력. 지위에서 나오는 힘

이 세 가지를 종합하여, 군주가 개인적 덕이나 현명함에 의존하지 않고도 나라를 효율적으로 다스릴 수 있는 **제도적 통치 시스템**을 설계했습니다.
