## 근사록이란?

『근사록』은 **주희와 여조겸이 북송의 4명 큰 학자(주돈이·정호·정이·장재)의 저술과 어록 가운데 가장 핵심적인 622조를 뽑아, 14개 분야로 분류·편집한 신유학(新儒學)의 종합 교과서**입니다.

서명 '근사(近思)'는 『논어』에서 자하(子夏)가 말한 "**박학이독지 절문이근사(博學而篤志 切問而近思)**" — "널리 배우고 뜻을 돈독히 하며, 절실하게 묻고 가까이 생각하라"에서 따왔습니다. 즉 **"고원한 이론이 아니라 내 몸 가까이의 절실한 문제부터 생각하라"**는 정신을 책 이름에 담은 것입니다.

우주의 본체(도체)부터 일상 수양·가정·정치·교육·이단 분별·성현 모범에 이르기까지 **"성리학의 모든 것"을 가까운 데서 시작해 멀리까지 도달하도록** 단계적으로 안내하는 입문서이자 종합서입니다.

## 14편의 동심원적 구조

```
[권14] 관성현 — 누구를 본받을 것인가
   ↑
[권13] 변이단 — 무엇을 거를 것인가
   ↑
[권11~12] 교학·경계 — 적용과 점검
   ↑
[권7~10] 출처·치체·치법·정사 — 사회·정치
   ↑
[권6] 가도 — 가정
   ↑
[권2~5] 위학·치지·존양·극기 — 자기 수양
   ↑
[권1] 도체 — 형이상학적 토대
```

**개인의 내면 → 가정 → 사회·정치 → 교육·반성 → 분별·모범**으로 동심원처럼 확장. 『대학(大學)』의 **수신·제가·치국·평천하** 구조와 정확히 대응.

## 한국에서의 위상

- 고려 말 원나라에서 수입, 1370년 진주에서 첫 간행
- 조선 사대부의 **성리학 입문 정본**
- **퇴계 이황** 『근사록석의』, **이익** 『근사록질서』 등 한국 학자의 주석 다수
- 경연(經筵)에서 왕에게 진강된 텍스트 — 중종·영조·정조 모두 중시

## 한 문장 요약

> **『근사록』은 우주의 본체에서 시작해 자기 마음·가정·정치·교육·이단 분별·성인 모범까지를 14편 622조로 체계화한, "학문의 모든 것을 가까이서 시작해 멀리까지 도달하게 하는" 신유학의 종합 입문서이자 동아시아 800년 사대부 정신 교육의 정수이다.**
