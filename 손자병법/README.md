## 손자병법 한눈에 보기

| 개념 | 한자 | 의미 | 대표 구절 |
|------|------|------|----------|
| 부전승 | 不戰勝 | 싸우지 않고 이기다 | 不戰而屈人之兵 善之善者也 |
| 지피지기 | 知彼知己 | 적과 나를 알다 | 知彼知己 百戰不殆 |
| 오사 | 五事 | 다섯 근본 요소 | 道天地將法 |
| 졸속 | 拙速 | 서투르나 빠른 것 | 兵聞拙速 未睹巧之久 |
| 허실 | 虛實 | 빈곳과 찬곳 | 避實而擊虛 |
| 기정 | 奇正 | 기습과 정공법 | 以正合 以奇勝 |
| 세 | 勢 | 형세의 에너지 | 激水之疾 至於漂石者 勢也 |
| 풍림화산 | 風林火山 | 바람·숲·불·산 | 其疾如風 其徐如林 |
| 사지즉전 | 死地則戰 | 죽을 곳에서 싸워라 | 投之亡地然後存 |
| 선지 | 先知 | 미리 아는 것 | 成功出於衆者 先知也 |
