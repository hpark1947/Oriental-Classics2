# 시경(詩經)

## 개요

| 항목 | 내용 |
|------|------|
| 명칭 | 시경(詩經), 모시(毛詩) |
| 편찬 | 공자(孔子)가 3,000여 편에서 305편을 선별(전승) |
| 시대 | 서주(西周) 초기 ~ 춘추(春秋) 중기 (BC 11세기~BC 6세기경) |
| 구성 | 풍(風) 160편 + 아(雅) 105편 + 송(頌) 40편 = 총 305편 |
| 핵심 사상 | 시언지(詩言志), 온유돈후(溫柔敦厚), 흥관군원(興觀群怨) |
| 성격 | 유가 오경(五經)의 하나, 중국 최초의 시가 총집 |

## 시경이란?

시경(詩經)은 중국에서 가장 오래된 시가(詩歌) 모음집으로, **약 500년간의 시 305편**을 수록하고 있습니다. 원래 '시(詩)' 또는 '시삼백(詩三百)'이라 불렀으나, 한나라 때 경전의 지위를 얻어 '시경(詩經)'이 되었습니다.

전승에 따르면 공자가 원래 3,000여 편의 시 중에서 305편을 선별하여 정리했다고 합니다. 공자는 **"시 삼백을 한마디로 말하면 '생각에 사악함이 없다(思無邪)'"**고 평가했습니다.

시경의 시들은 단순한 문학 작품이 아니라, 당시의 **정치·사회·풍속·남녀 관계·제사·전쟁** 등을 생생하게 반영하는 역사적 자료이기도 합니다.

## 시경의 여섯 가지 원리 - 육의(六義)

시경을 이해하는 핵심 틀로, 세 가지 내용 분류(풍·아·송)와 세 가지 표현 기법(부·비·흥)이 있습니다.

### 내용에 따른 분류
1. **풍(風)**: 각 지방의 민요, 백성들의 노래
2. **아(雅)**: 궁중의 공식 연회나 조회에서 부르는 노래
3. **송(頌)**: 종묘 제사에서 조상의 덕을 찬양하는 노래

### 표현 기법
1. **부(賦)**: 직접 서술, 있는 그대로 표현
2. **비(比)**: 비유, 다른 사물에 빗대어 표현
3. **흥(興)**: 먼저 다른 사물을 들어 시상을 이끌어냄 (연상 유발)

## 시경의 문학적 가치

### 1. 사실주의 문학의 원류
시경은 중국 사실주의 문학의 시조로, 백성들의 실제 삶과 감정을 있는 그대로 노래합니다.

### 2. 서정시의 전범
사랑, 이별, 그리움, 분노, 기쁨 등 인간의 보편적 감정을 아름답게 표현하여 동아시아 서정시의 원형이 되었습니다.

### 3. 역사적 자료
서주~춘추 시대의 정치, 사회, 풍속, 농업, 전쟁, 제사 등을 생생하게 보여주는 1차 사료입니다.

### 4. 공자의 시교(詩敎)
공자는 "시를 배우지 않으면 말할 수 없다(不學詩 無以言)"고 하여, 시경을 인격 수양과 언어 교육의 핵심 교재로 삼았습니다.
