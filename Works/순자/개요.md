# 순자 개요

---

## 1. 정의

순자(荀子, Xunzi)는 전국시대 말기의 유학자 **순황(荀況)**의 사상을 담은 저작으로, 총 **32편**으로 구성된 유가 철학서이다. 논어·맹자가 어록과 대화 중심인 것과 달리, 순자는 **논설문(論說文)** 형식으로 체계적 논증을 전개한 최초의 유가 저작이다.

| 항목 | 내용 |
|------|------|
| 서명 | 순자(荀子) |
| 저자 | 순황(荀況, BC 313?~BC 238?) |
| 시대 | 전국시대 말기(戰國末期) |
| 편수 | 32편 |
| 형식 | 논설문 중심 |
| 성격 | 유가 철학의 체계적 논증서 |
| 사상 핵심 | 성악설(性惡說), 예론(禮論), 천론(天論) |
| 사서 지위 | 선진 유학의 3대 저작 (논어·맹자·순자) |

---

## 2. 편찬 과정

순자의 편찬은 크게 세 단계로 이루어졌다:

- **1차 저술**: 순황이 직접 저술한 핵심 논문들 — 권학, 성악, 예론, 천론, 정명, 해폐 등 주요 편은 순황 본인의 저작으로 인정된다.
- **2차 편집**: 순황의 제자들(이사·한비자 등)이 스승의 강의록과 토론 내용을 정리하여 추가 — 대략·유좌·요문·자도·법행 등은 제자 정리본으로 추정된다.
- **3차 교정**: 한(漢)나라 유향(劉向)이 전해지던 322편의 서적을 정리하여 32편으로 교정·편집하였다. 현행본의 편차와 체제는 유향의 교정에 기반한다.

당(唐)나라 양량(楊倞)이 최초의 주석서를 편찬하여 현행 20권 32편의 체제를 확립하였으며, 청(清)나라 왕선겸(王先謙)의 《순자집해(荀子集解)》가 가장 권위 있는 주석서로 인정된다.

## 3. 순황(荀況)

| 항목 | 내용 |
|------|------|
| 성명 | 순황(荀況), 자(字)는 경(卿) |
| 별칭 | 순경(荀卿), 손경(孫卿) |
| 출생 | BC 313년경, 조(趙)나라 |
| 사망 | BC 238년경, 초(楚)나라 난릉(蘭陵) |
| 활동 | 제(齊)나라 직하학궁(稷下學宮), 초나라 난릉령(蘭陵令) |
| 제자 | 이사(李斯), 한비자(韓非子), 부구백(浮丘伯) 등 |
| 학파 | 유가(儒家), 그러나 법가에도 영향 |

### 생애 요약

- **유년기·청년기**: 조나라 출신으로 15세경 제나라 직하학궁에 유학
- **직하학궁 시기**: 세 차례 **제주(祭酒, 학장)**를 역임하며 직하학궁의 최고 학자로 명성을 얻음
- **초나라 시기**: 초나라 춘신군(春申君)의 초청으로 난릉령에 취임
- **저술 시기**: 춘신군 사후 관직에서 물러나 난릉에 머물며 저술에 전념
- **만년**: 난릉에서 제자를 가르치며 여생을 보냄

### 사상사적 위치

순황은 **공자·맹자의 유가 전통을 계승하면서도 독자적 사상 체계를 수립**한 인물이다:

- 맹자의 **성선설**에 대해 **성악설**을 주장하여 유가 내부의 치열한 논쟁을 일으킴
- **예(禮)**를 인간 사회의 근본 원리로 체계화하여 유가 예학의 이론적 토대를 마련
- **천(天)**을 자연 현상으로 규정하여 유가 사상에 합리주의적 요소를 도입
- 제자 이사·한비자를 통해 **법가(法家)** 사상에도 결정적 영향을 미침

## 4. 순자의 구성: 32편

순자 32편은 내용과 성격에 따라 크게 네 부분으로 분류할 수 있다.

### 핵심 사상편 (제1~9편)

| 편 | 편명 | 핵심 주제 |
|----|------|-----------|
| 1 | 권학(勸學) | 학문의 권장, 적(積)의 사상 |
| 2 | 수신(修身) | 자기 수양의 방법 |
| 3 | 불구(不苟) | 올바른 처신, 성(誠)의 강조 |
| 4 | 영욕(榮辱) | 영예와 치욕의 분별 |
| 5 | 비상(非相) | 관상학 비판, 실질 중시 |
| 6 | 비십이자(非十二子) | 제자백가 비판 |
| 7 | 중니(仲尼) | 공자 사상의 계승과 발전 |
| 8 | 유효(儒效) | 유학의 효용과 가치 논증 |
| 9 | 왕제(王制) | 예의 기반 국가 제도론 |

### 경세 실천편 (제10~16편)

| 편 | 편명 | 핵심 주제 |
|----|------|-----------|
| 10 | 부국(富國) | 경제론, 국부(國富)의 원리 |
| 11 | 왕패(王霸) | 왕도와 패도의 비교 |
| 12 | 군도(君道) | 군주의 통치 도리 |
| 13 | 신도(臣道) | 신하의 도리 |
| 14 | 치사(致士) | 인재 등용론 |
| 15 | 의병(議兵) | 군사론, 예의 기반 병법 |
| 16 | 강국(强國) | 국가 강성의 조건 |

### 철학 심화편 (제17~23편)

| 편 | 편명 | 핵심 주제 |
|----|------|-----------|
| 17 | 천론(天論) | 천인분리, 자연관 |
| 18 | 정론(正論) | 정치 이론의 정정(正正) |
| 19 | 예론(禮論) | 예의 기원·기능·체계 |
| 20 | 악론(樂論) | 음악의 사회적 기능 |
| 21 | 해폐(解蔽) | 인식론, 허일이정 |
| 22 | 정명(正名) | 명실론, 언어 철학 |
| 23 | 성악(性惡) | 성악설, 화성기위 |

### 부록·잡편 (제24~32편)

| 편 | 편명 | 핵심 주제 |
|----|------|-----------|
| 24 | 군자(君子) | 군자의 자질과 도리 |
| 25 | 성상(成相) | 운문 형식의 정치 풍자 |
| 26 | 부(賦) | 문학 작품(부) |
| 27 | 대략(大略) | 격언·잡록 모음 |
| 28 | 유좌(宥坐) | 공자 일화 모음 |
| 29 | 자도(子道) | 자녀의 도리 |
| 30 | 법행(法行) | 법도 있는 행실 |
| 31 | 애공(哀公) | 노나라 애공과 공자의 대화 |
| 32 | 요문(堯問) | 요순 관련 문답 |

## 5. 역사적 의의와 영향

### 사상사적 의의

1. **유가 철학의 체계화**: 어록·대화 중심이었던 유가 사상을 최초로 논리적 논설문 형식으로 체계화
2. **성악설의 제기**: 맹자의 성선설에 대한 반론으로 인간 본성에 대한 심층 논쟁을 촉발
3. **예학의 이론적 토대**: 예(禮)를 감정 조절과 사회 질서의 핵심 원리로 체계적 논증
4. **합리주의적 천론**: 하늘을 자연 현상으로 규정하여 유가에 합리주의 전통을 수립
5. **명실론(名實論)**: 언어와 실재의 관계에 대한 체계적 분석으로 중국 언어 철학의 기초를 마련

### 후대 영향

| 영향 분야 | 주요 내용 |
|-----------|-----------|
| 법가(法家) | 제자 이사·한비자를 통해 진(秦)나라 통치 이념에 결정적 영향 |
| 한대 유학 | 한나라 초기 유학은 순자 계열의 영향이 맹자 계열보다 컸음 |
| 예학(禮學) | 예기(禮記)의 이론적 기반, 후대 예학 발전의 원천 |
| 송명 이학 | 성리학에서 배척되었으나, 이기론·수양론에 간접적 영향 |
| 청대 고증학 | 순자에 대한 재평가와 본격적 연구 시작 |
| 근현대 | 20세기 이후 재조명, 합리주의·자연주의적 측면에서 높은 평가 |

### 논어·맹자와의 비교

| 비교 항목 | 논어 | 맹자 | 순자 |
|-----------|------|------|------|
| 시대 | 춘추 말기 | 전국 중기 | 전국 말기 |
| 형식 | 어록·문답 | 대화·논변 | 논설문 |
| 핵심 인성론 | 성상근(性相近) | 성선설(性善說) | 성악설(性惡說) |
| 수양 방법 | 학(學)·극기복례 | 존심양성(存心養性) | 화성기위(化性起僞) |
| 천(天)의 성격 | 도덕적 천 | 의지적 천 | 자연적 천 |
| 사회 질서 원리 | 인(仁)·예(禮) | 인의(仁義) | 예(禮)·법(法) |
| 편수 | 20편 | 7편 14장 | 32편 |
