# 육도삼략(六韜三略)

## 개요

육도삼략은 **육도(六韜)**와 **삼략(三略)** 두 병법서를 합쳐 부르는 이름이다. 송(宋)나라 때 공식 선정된 **무경칠서(武經七書)** 7종 가운데 2종을 차지하는 유일한 조합으로, 동아시아 군사학의 핵심 고전이다.

| 구분 | 육도(六韜) | 삼략(三略) |
|------|----------|----------|
| 전승 저자 | 태공망(太公望) 여상(呂尙) | 황석공(黃石公) |
| 규모 | 6권 60편 | 3편, 약 3,800자 |
| 형식 | 주 문왕·무왕과 태공의 문답 | 논술 + 군참·군세 인용 |
| 성격 | 종합 통치서 + 군사 전략서 | 리더십·정치 철학서 |
| 핵심 사상 | 천하공유론, 인재 중심주의 | 유능제강(柔能制剛), 강유 조화 |

## 핵심 사상

### 1. 천하공유론(天下公有論)
> 천하는 한 사람의 천하가 아니라, 천하 사람 모두의 천하이다.

### 2. 인재 중심주의
> 나라를 다스리고 집을 편안하게 하는 것은 사람을 얻은 것이고, 나라를 망하게 하고 집을 깨뜨리는 것은 사람을 잃은 것이다.

### 3. 유능제강(柔能制剛)
> 부드러움이 능히 굳셈을 제어하고, 약함이 능히 강함을 제어한다.

### 4. 강유 조화(剛柔調和)
> 부드러울 수도 굳셀 수도 있으면 그 나라가 더욱 빛나고, 순전히 강하기만 하면 그 나라가 반드시 망한다.
