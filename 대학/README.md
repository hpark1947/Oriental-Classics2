# 대학(大學)

## 개요

| 항목 | 내용 |
|------|------|
| 원전 | 예기(禮記) 제42편 |
| 저자 | 경문(經文) - 공자(孔子), 전문(傳文) - 증자(曾子) |
| 독립 편찬 | 주희(朱熹)가 사서(四書)의 하나로 독립시킴 |
| 구성 | 경(經) 1장 + 전(傳) 10장 |
| 핵심 사상 | 삼강령(三綱領)과 팔조목(八條目) |
| 성격 | 유학의 목적과 방법을 체계적으로 제시한 정치·수양론의 핵심 |

## 대학이란?

대학(大學)은 '큰 배움'을 뜻합니다. 소학(小學)에서 일상의 예절과 기본 도리를 배운 뒤, 15세 이후에 들어가는 **고등 교육 과정**의 핵심 교재입니다.

원래 예기(禮記)의 한 편이었으나, 주희(朱子)가 이를 독립시켜 논어, 맹자, 중용과 함께 **사서(四書)**의 하나로 삼았습니다. 주희는 대학을 사서 중 **가장 먼저 읽어야 할 책**으로 지정했는데, 유학의 전체 구조와 목표를 한눈에 보여주는 '입문의 문(入德之門)'이라 여겼기 때문입니다.

대학의 핵심은 **삼강령(三綱領)**과 **팔조목(八條目)**입니다. 삼강령은 유학의 세 가지 큰 목표이고, 팔조목은 그 목표에 이르는 여덟 단계의 실천 방법입니다.

## 삼강령(三綱領) - 세 가지 큰 목표

1. **명명덕(明明德)** - 밝은 덕을 밝힘: 모든 사람에게 본래 갖추어진 선한 본성(명덕)을 밝게 드러내는 것
2. **친민(親民) / 신민(新民)** - 백성을 새롭게 함: 자신의 덕을 밝힌 뒤 다른 사람도 새롭게 변화시키는 것
3. **지어지선(止於至善)** - 지극한 선에 머무름: 최고의 선한 경지에 도달하여 머무는 것

## 팔조목(八條目) - 여덟 단계의 실천

| 순서 | 조목 | 의미 | 범위 |
|------|------|------|------|
| 1 | 격물(格物) | 사물의 이치를 궁구함 | 지(知) |
| 2 | 치지(致知) | 앎을 극진히 함 | 지(知) |
| 3 | 성의(誠意) | 뜻을 성실히 함 | 수양 |
| 4 | 정심(正心) | 마음을 바르게 함 | 수양 |
| 5 | 수신(修身) | 몸을 닦음 | 수양 |
| 6 | 제가(齊家) | 가정을 가지런히 함 | 실천 |
| 7 | 치국(治國) | 나라를 다스림 | 실천 |
| 8 | 평천하(平天下) | 천하를 평안히 함 | 실천 |
