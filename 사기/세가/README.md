# 사기 세가(世家) 30편 — 한눈에 보기

## 세가란 무엇인가

사기 130권의 5부 중 하나.
- 본기(本紀) 12편 — 천자의 전기
- 표(表) 10편 — 연표
- 서(書) 8편 — 제도·문화 사
- **세가(世家) 30편** — **제후국·제후의 전기**
- 열전(列傳) 70편 — 인물 전기

세가는 본래 **세습되는 제후국·제후 가문**의 전기. 그러나 사마천은 이를 넘어 **사실상 큰 영향력을 가진 자**라면 격식에 매이지 않고 세가에 넣었다.

## 사마천의 세가 구성의 두 파격

본기에 항우·여태후를 넣은 두 파격에 이어, 세가에서도 두 파격:

1. **공자세가(권17)** — 제후가 아닌 한 학자를 세가에 — **정신적 권력에 대한 경의**
2. **진섭세가(권18)** — 평민 농민 봉기 지도자를 세가에 — **첫 봉기의 가치 인정**

→ **격식이 아닌 실질**을 본 사마천 사관의 위대함이 세가에서도 빛난다.

## 세가 30편의 큰 흐름

```
[1~16] 춘추전국 제후국 — 약 800년 흥망
       ↓
[17~18] 사마천의 두 파격 — 공자·진섭
       ↓
[19~30] 한대 외척·종실·재상 — 자기 시대
```

## 세가 30편이 그리는 큰 그림

세가는 본기와 짝을 이룬다. **본기가 천자의 시점**이라면, **세가는 제후·재상·평민까지 다양한 시점**.

특히 사마천은 세가에서 **"누가 진짜 영향력 있는가"**를 묻고, 격식에 매이지 않고 답했다:
- 양보의 정신(태백)에서 시작
- 관중·자산·인상여 같은 명재상의 모습
- 와신상담의 인내
- 송양지인의 어리석음
- 공자의 정신적 위대함
- 진섭의 첫 봉기의 용기
- 한삼걸의 다양한 길 (소하·장량·한신)
- 종실 봉건의 양면

→ **천하를 호령한 자, 천하를 가르친 자, 천하를 흔든 자 모두를 본기가 아닌 세가에**.

## 한 문장 요약

> **"사기 세가 30편은 춘추 시대 제후국 16편에서 시작해 사마천의 두 파격(공자·진섭)을 거쳐 한대 종실·외척·재상 12편으로 끝나는,**
> **'천자만이 아닌, 천하를 움직인 모든 자'의 일대기를 격식에 매이지 않고 그린**
> **사마천 사관의 위대한 결정이다."**
