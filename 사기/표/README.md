# 사기 표(表) 10편 — 한눈에 보기

## 표란 무엇인가

사기 130권의 5부 중 하나.
- 본기(本紀) 12편 — 천자의 전기
- **표(表) 10편** — **연표·세계표**
- 서(書) 8편 — 제도 사
- 세가(世家) 30편 — 제후국 전기
- 열전(列傳) 70편 — 인물 전기

표는 **공시적(共時的) 역사 이해의 도구**. 본기·세가·열전이 인물·시대 중심이라면, 표는 **여러 나라·여러 인물의 같은 시기 일을 한눈에 본다**.

## 사마천의 표 구성의 위대함

사마천은 표 10편에 두 가지 위대한 결정:
1. **확실한 연대(BC 841)부터만 연표** — 그 이전은 세계표만. 사관의 정직
2. **인물 중심 + 정권 중심 + 봉건 중심의 다양한 표** — 다각적 시각

→ **공시적 역사 이해의 첫 모범**.

## 사마천의 표 사관 — 핵심

### 1. **확실한 연대 인식**
- BC 841 (공화 원년) 이전은 모름
- "모르는 것은 모른다"

### 2. **공시적 역사 이해**
- 같은 해 여러 나라가 어떻게 움직였는가
- 후세 모든 연표의 모범

### 3. **사회·정치 변동 추적**
- 봉건제 흥망
- 공신 가문 흥망
- 추은령의 결과

## 한 문장 요약

> **"사기 표 10편은 황제 시대 세계표에서 시작해 한대 장상명신연표로 끝나는,**
> **'공시적 역사 이해'의 첫 모범이자 본기·세가·열전을 시간 축에서 종합하는 사기의 골격이다."**
