# 사기 본기(本紀) 12편 — 한눈에 보기

## 본기란 무엇인가

『사기』는 5부 130권으로 구성된다.
- **본기(本紀) 12편** — 역대 천자(황제)의 전기
- **표(表) 10편** — 연표
- **서(書) 8편** — 제도·문화·경제 사
- **세가(世家) 30편** — 제후국의 역사
- **열전(列傳) 70편** — 인물 전기

본기는 그 첫머리이자 책 전체의 골격. **천자의 전기를 시간순으로 배열**하여 약 2,500년의 통사를 그린다.

## 사마천의 본기 구성의 파격

본기는 원래 **천자(황제)**의 전기. 그러나 사마천은 두 가지 파격을 단행했다:
1. **항우본기** — 항우는 천자가 된 적 없는 패왕(覇王)이지만 본기에 넣음
2. **여태후본기** — 여후는 황제가 아닌 황태후이지만 본기에 넣음

이유: **격식이 아닌 실질**을 본 것. "그 시대를 실제로 호령한 자"를 본기에 넣음. 사마천 사관(史觀)의 위대함.

## 본기를 관통하는 핵심 패턴

본기 12편을 순서대로 읽으면 **흥망의 보편 패턴**이 보인다.

### 흥(興)의 패턴
- 시조는 평민 또는 변방 출신 (요·탕·문왕·유방)
- **덕(德)으로 백성의 마음을 얻음**
- 인재를 알아보고 등용 (강태공·이윤·장량·소하)
- 검소·관용·간언 수용

### 망(亡)의 패턴
- 마지막 임금은 사치·폭정 (걸·주·진시황·항우)
- 신하의 간언 무시
- 백성 수탈
- **민심을 잃는 순간 천명이 떠남**

→ 사마천이 본기 전체로 보여 주려 한 것은 결국 **"왕조 흥망의 거울"**. 후세 군주가 자기를 점검할 수 있는 영원한 거울.

## 사기 본기의 12개 명장면 — 각 편의 가장 인상적 일화

| 본기 | 명장면 |
|------|--------|
| 1 오제 | **요·순의 선양** — 자기 자식 아닌 어진 자에게 천하를 물려줌 |
| 2 하 | **삼과기문이불입(三過其門而不入)** — 우의 13년 헌신 |
| 3 은 | **망개삼면(網開三面)** — 탕왕의 자비로 천하 얻음 |
| 4 주 | **강태공의 위수 낚시** — 70 노인 발굴 |
| 5 진 | **이목지신(移木之信)** — 상앙의 신뢰 구축 |
| 6 진시황 | **분서갱유**와 **지록위마(指鹿爲馬)** — 절대 권력의 부패 |
| 7 항우 | **사면초가(四面楚歌)와 패왕별희(霸王別姬)** — 영웅의 비극 |
| 8 고조 | **유방의 자기 평가** ("장량보다 못하다, 소하보다 못하다…") |
| 9 여태후 | **인체(人彘) 사건** — 권력 잔혹의 극치 |
| 10 효문 | **친상탕약(親嘗湯藥)** — 황제의 효 |
| 11 효경 | **7국의 난 평정** — 봉건제 종결 |
| 12 효무 | **사마천의 궁형(宮刑)** — 사관의 비극 |

## 한국·일본의 사기 수용

- **한국**: 조선 사대부의 필독서. 김원중·정범진 등의 한국어 완역본 있음.
- **일본**: 도쿠가와 시대부터 사기 강독 활발. 시바 료타로의 역사 소설들이 사기에서 영감.

## 읽는 법

1. **순서대로** — 권1 오제부터 권12 효무까지 — 시간 순으로 읽으면 흥망 패턴이 보임
2. **명장면 중심** — 위 12개 명장면을 먼저 읽고 흥미 끌리는 본기 깊이 읽기
3. **두 인물 비교 읽기** — **항우 vs. 유방**, **걸 vs. 탕**, **주왕 vs. 무왕** 같은 대비
4. **명군·폭군 분리 읽기** — 명군(요·순·탕·문왕·유방·문제) vs. 폭군(걸·주·진시황·항우)
5. **자기 시대에 비추기** — 어느 본기가 오늘 우리 시대와 비슷한가?

## 한 문장 요약

> **"사기 본기 12편은 황제(黃帝)에서 한 무제(漢武帝)까지 약 2,500년의 통사이며,**
> **흥하는 자와 망하는 자의 보편 패턴을 12명의 천자(또는 패자) 일대기로 그려낸,**
> **사마천이 자기 궁형의 치욕 위에서 완성한 동양 역사 서술의 영원한 모범이다."**
