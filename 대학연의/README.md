## 🗂️ 권차별 — 강령 — 상세

### 제1부 — 서론 (권1~4, 4권)

**帝王爲治之序** — 제왕의 — 다스림의 차례
**帝王爲學之本** — 제왕의 — 학문의 근본

### 제2부 — 格物致知之要 (권5~12, 8권)

4가지 — 강령:

1. **明道術** (명도술) — 도의 술(이치)을 — 밝힘
2. **辨人材** (변인재) — 군자와 소인의 — 분별
3. **審民情** (심민정) — 백성의 정을 — 살핌
4. **察民治** (찰민치) — 지난 정치를 — 살핌

### 제3부 — 誠意正心之要 (권13~22, 10권)

2가지 — 강령:

1. **崇敬畏** (숭경외) — 경외를 — 높임
2. **戒逸欲** (계일욕) — 방종·욕망을 — 경계

### 제4부 — 修身之要 (권23~32, 10권)

2가지 — 강령:

1. **謹言行** (근언행) — 말과 행동을 — 삼감
2. **正威儀** (정위의) — 위엄과 의례를 — 바르게 함

### 제5부 — 齊家之要 (권33~43, 11권)

4가지 — 강령:

1. **重妃匹** (중비필) — 배필을 — 중히 여김 (황후 선택)
2. **嚴內治** (엄내치) — 내정을 — 엄히 함 (후궁·환관 절제)
3. **定國本** (정국본) — 국본을 — 정함 (황태자 교육)
4. **敎戚屬** (교척속) — 척속을 — 가르침 (외척 통제)

### 명대 보완 — 治國·平天下

**구준(丘濬, 1421~1495)**의 — 「**대학연의보**」 160권. **1487년**.

진덕수의 — 「**치국·평천하 — 미완성**」을 — 250년 후 — 보완.

## 🎯 읽기 추천 순서

1. 종합 → 1부(서론) → **3부(성의정심)** → **2부(격물치지)** → 4부(수신) → 5부(제가) → 6부(보완)

### 정치·통치를 — 관심 두는 독자

1. 종합 → 1부 → **2부(격물치지의 변인재)** → 5부(제가) → 6부(치국·평천하 보완)
