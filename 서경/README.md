# 서경(書經) / 상서(尙書)

## 개요

| 항목 | 내용 |
|------|------|
| 명칭 | 서경(書經), 상서(尙書), 서(書) |
| 기원 | 요순시대 ~ 주나라 초기의 정치 문서 |
| 시대 | 요순(堯舜) ~ 동주(東周) 초기 (전설시대~BC 8세기경) |
| 구성 | 우서(虞書) + 하서(夏書) + 상서(商書) + 주서(周書), 현존 58편 중 33편이 금문(今文) |
| 핵심 사상 | 천명(天命), 덕치(德治), 민본(民本), 경천근민(敬天勤民) |
| 성격 | 유가 오경(五經)의 하나, 중국 최초의 역사·정치 산문집 |

## 서경이란?

서경(書經)은 중국에서 가장 오래된 **정치 문서와 역사 기록의 모음집**입니다. '상서(尙書)'라고도 하며, '상(尙)'은 '위(上)', 즉 '옛것'을 뜻하여 **'옛 문서'**라는 의미입니다.

요(堯)·순(舜) 임금 시대부터 하(夏)·상(商)·주(周) 삼대(三代)에 이르기까지, 제왕들의 **훈시, 명령, 서약, 선언, 대화** 등을 기록한 것으로, 동양 정치 사상의 원천입니다.

서경은 단순한 역사서가 아니라, **이상적인 정치란 무엇인가**에 대한 답을 담고 있습니다. 하늘의 뜻(天命)을 받들어 덕으로 다스리고(德治), 백성을 근본으로 삼는(民本) 정치 철학이 서경의 핵심입니다.

## 금문상서와 고문상서

서경의 전승 과정은 매우 복잡합니다.

| 구분 | 금문상서(今文尙書) | 고문상서(古文尙書) |
|------|---------------------|---------------------|
| 시기 | 한초 복생(伏生)이 구전으로 전함 | 공자 구택에서 발견(전승) |
| 문자 | 한대 예서(隸書)로 기록 | 선진 시대 고문(古文)으로 기록 |
| 편수 | 28편(또는 29편) | 추가 25편 |
| 진위 | 대체로 진본으로 인정 | 위고문(僞古文) 논쟁 |
| 현존 | 현행 58편 중 33편 | 현행 58편 중 25편 |

청대 염약거(閻若璩)가 고문상서 25편이 위작(僞作)임을 고증했으나, 그 사상적 가치는 여전히 인정됩니다.

## 문체의 종류 - 육체(六體)

서경의 글은 여섯 가지 문체로 분류됩니다.

| 문체 | 한자 | 의미 | 예시 |
|------|------|------|------|
| 전(典) | 典 | 제왕의 행적과 법도 기록 | 요전, 순전 |
| 모(謨) | 謨 | 군신 간의 모략·의논 | 대우모, 고요모 |
| 훈(訓) | 訓 | 신하가 군주에게 올리는 가르침 | 이훈 |
| 고(誥) | 誥 | 군주가 신하·백성에게 내리는 훈시 | 탕고, 대고 |
| 서(誓) | 誓 | 출전·출정 시의 서약 | 감서, 목서 |
| 명(命) | 命 | 군주가 신하에게 내리는 명령 | 열명, 문후지명 |

## 구성

### 우서(虞書) - 5편

요순시대의 이상 정치를 기록한 편으로, 선양(禪讓)의 이상과 덕치의 원형을 담고 있습니다.

| 편명 | 핵심 내용 |
|------|-----------|
| 요전(堯典) | 요임금의 성덕과 치세, 순에게 선양 |
| 순전(舜典) | 순임금의 등용과 치세, 관직 설치 |
| 대우모(大禹謨) | 우(禹)에 대한 순임금의 훈시, 치수 |
| 고요모(皐陶謨) | 고요(皐陶)의 정치론, 구덕(九德) |
| 익직(益稷) | 익(益)과 직(稷)의 정치 보좌 |

### 하서(夏書) - 4편

하나라의 역사, 특히 우왕의 치수와 국토 정리를 기록합니다.

| 편명 | 핵심 내용 |
|------|-----------|
| 우공(禹貢) | 구주(九州)의 지리·공물·토질 (중국 최초의 지리서) |
| 감서(甘誓) | 유호씨 정벌 전 하우의 서약 |
| 오자지가(五子之歌) | 태강(太康)의 실정을 한탄하는 다섯 형제의 노래 |
| 윤정(胤征) | 의(羲)·화(和)의 직무 태만 정벌 |

### 상서(商書) - 17편

상(은)나라의 건국, 흥망, 정치를 기록합니다.

| 편명 | 핵심 내용 |
|------|-----------|
| 탕서(湯誓) | 탕왕의 하나라 정벌 서약 |
| 중훼지고(仲虺之誥) | 중훼가 탕왕에게 올린 훈고 |
| 탕고(湯誥) | 탕왕이 천하에 내린 훈시 |
| 이훈(伊訓) | 이윤이 태갑에게 올린 훈계 |
| 태갑(太甲) 상·중·하 | 태갑의 유배와 회개, 복위 |
| 함유일덕(咸有一德) | 이윤이 일덕(一德)의 중요성을 강조 |
| 반경(盤庚) 상·중·하 | 반경의 천도(遷都) 설득 |
| 열명(說命) 상·중·하 | 고종이 부열(傅說)을 등용하고 정치를 논함 |
| 고종융일(高宗肜日) | 제사에 관한 훈계 |
| 서백감려(西伯戡黎) | 서백(문왕)의 여(黎) 정벌 소식 |
| 미자(微子) | 은나라 말기 미자의 고민과 결단 |

### 주서(周書) - 32편

주나라의 건국과 정치를 기록한 가장 방대한 부분입니다.

| 편명 | 핵심 내용 |
|------|-----------|
| 태서(泰誓) 상·중·하 | 무왕의 은나라 정벌 서약 |
| 목서(牧誓) | 목야 전투 직전 무왕의 서약 |
| 무성(武成) | 무왕의 은나라 정복 과정 |
| 홍범(洪範) | 기자(箕子)가 전한 구주홍범(九疇), 정치의 대법 |
| 금등(金縢) | 주공이 무왕 대신 죽기를 빈 이야기 |
| 대고(大誥) | 주공이 은나라 유민 반란 토벌을 선포 |
| 미자지명(微子之命) | 미자를 송나라에 봉하는 명령 |
| 강고(康誥) | 강숙을 위나라에 봉하며 내린 훈시 |
| 주고(酒誥) | 술의 해악을 경계하는 훈시 |
| 재재(梓材) | 나라 다스리기를 목재 다루기에 비유 |
| 소고(召誥) | 소공의 낙읍 건설과 훈시 |
| 낙고(洛誥) | 주공의 낙읍 완성 보고 |
| 다사(多士) | 은나라 유민에 대한 훈시 |
| 무일(無逸) | 주공이 성왕에게 안일을 경계 |
| 군석(君奭) | 주공이 소공에게 보좌를 당부 |
| 채중지명(蔡仲之命) | 채중을 채나라에 봉하는 명령 |
| 다방(多方) | 여러 제후국에 대한 훈시 |
| 입정(立政) | 관리 임용의 원칙 |
| 주관(周官) | 주나라 관직 체계 |
| 군진(君陳) | 군진에게 낙읍 통치를 맡기는 명령 |
| 고명(顧命) | 성왕의 유명(遺命)과 강왕 즉위 |
| 강왕지고(康王之誥) | 강왕 즉위 후 신하들에게 내린 훈시 |
| 필명(畢命) | 필공에게 내린 명령 |
| 군아(君牙) | 군아에게 내린 명령 |
| 경명(冏命) | 백경에게 내린 명령 |
| 여형(呂刑) | 형벌의 원칙과 신중한 적용 |
| 문후지명(文侯之命) | 진나라 문후에게 내린 명령 |
| 비서(費誓) | 동방 정벌의 서약 |
| 진서(秦誓) | 진 목공의 패전 후 자기반성 |

## 핵심 사상

### 1. 천명(天命)
하늘이 덕 있는 자에게 천하를 맡기고, 덕을 잃으면 거두어간다. 왕조 교체의 정당성을 하늘의 뜻으로 설명.

### 2. 덕치(德治)
덕(德)으로 다스리는 것이 정치의 근본. 형벌보다 교화를, 위력보다 덕행을 앞세움.

### 3. 민본(民本)
"백성은 나라의 근본이니 근본이 튼튼해야 나라가 평안하다(民惟邦本 本固邦寧)." 민심이 곧 천심.

### 4. 경천근민(敬天勤民)
하늘을 공경하고 백성을 위해 부지런히 힘쓰는 것이 제왕의 도리.
